# superagent-lab

superagent-lab 是 dsh-superagent 的公开演练仓库，用来验证从 Issue 到 PR 的完整自动化协作流程。

dsh-superagent 练手靶场：空仓，弄坏不心疼
hello from superagent

## 安装

无需安装依赖，克隆即可开始：

```bash
git clone https://github.com/pinren/superagent-lab.git
cd superagent-lab
```

## 用法示例

在 Issue 里 @ agent 账号并描述需求，例如：

> @renpinagent 给 README 加一句定位。

agent 会在原 Issue 回复，完成后提交 PR；在 PR 里 review、合并即可。
